## Core Competencies
[](https://github.com/FNRodrigues05/Portfolio#core-competencies)

- **Systems & Architecture**: Low-level programming (Assembly RISC-V), process lifecycle, and memory management (C/Linux).
- **Network & Systems Programming**: Socket programming (TCP/UDP), I/O multiplexing, concurrency management (POSIX threads), and custom application-layer protocol design.
- **Mobile Development**: Native Android application architecture, focusing on decentralized networking simulation, UI/UX prototyping, and device state management.
- **Full-Stack Development**: Designing scalable backend REST APIs and consuming web services through dynamic front-end interfaces.
- **Data Structures & Algorithms**: Strong foundation in graph theory, network flow algorithms, and time/space complexity optimization.
- **Relational Databases**: Database schema design, relational algebra modeling, and complex SQL query optimization.
- **Digital Systems**: State machine design, Boolean algebra optimization (Karnaugh maps), and digital circuit simulation.
- **Linux Systems Administration**: Experience with environment setup, custom dual-boot configurations, partitioning, and bash scripting.
