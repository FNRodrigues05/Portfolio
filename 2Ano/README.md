# 2º Ano - Licenciatura em Engenharia Informática

Este repositório reúne os trabalhos desenvolvidos no **2º ano** da **Licenciatura em Engenharia Informática**, no ano letivo **2024/2025**.

## Sobre este Ano

O segundo ano da licenciatura aprofundou conhecimentos em áreas fundamentais como programação avançada, redes de computadores, bases de dados, estruturas de dados e computação gráfica. Os projetos realizados permitiram aplicar conceitos teóricos em trabalhos práticos e mais complexos.

## Trabalhos Incluídos

### Trabalho de Programação II

Na pasta de **Programação II** encontra-se um projeto em **Java** relacionado com o desenvolvimento de um jogo de palavras, com interface gráfica e regras de jogo mais elaboradas.

### Trabalho de Redes de Computadores

Na pasta de **Redes de Computadores** foi realizado um projeto sobre comunicação em rede, com implementação e análise de protocolos e comunicação entre sistemas.

### Trabalhos de Estruturas de Dados e Algoritmos II

Na pasta de **Estruturas de Dados E Algoritmos II** estão presentes vários trabalhos práticos sobre estruturas de dados, algoritmos e resolução de problemas computacionais.

### Trabalhos de Bases de Dados

Na pasta de **Base de Dados** encontram-se trabalhos relacionados com modelação, consulta e gestão de bases de dados, com foco em SQL e organização de informação.

### Trabalhos de Computação Gráfica

Na pasta de **Computação Gráfica** estão incluídos projetos em diferentes abordagens gráficas, como **SVG**, **Three.js**, **X3D** e **Canvas 2D**.

## Objetivo

Esta pasta reúne os projetos académicos do segundo ano, refletindo a evolução das competências em programação, rede, bases de dados e interfaces gráficas.
