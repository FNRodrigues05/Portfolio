# Robots Carnage

Este repositório contém o projeto **Robots Carnage**, desenvolvido no âmbito da **Prova de Aptidão Profissional (PAP)** do curso de **Programador Informático** da **Escola Profissional da Região Alentejo (EPRAL)**, no ano letivo **2022/2023**.

## Sobre o Projeto

O **Robots Carnage** é um jogo do tipo **FPS (First Person Shooter)** desenvolvido em **Unity** com **C#**. O objetivo principal é explorar vários níveis, encontrar chaves escondidas, libertar os companheiros do jogador e eliminar os inimigos robóticos que surgem ao longo da aventura.

O jogo inclui elementos de exploração e puzzle, com uma mecânica de combate simples e uma arma principal baseada numa **pistola laser**, bem como a possibilidade de utilizar um **impulso** para se esquivar.

## Funcionalidades Principais

- Menu principal com opções para **Jogar**, **Opções**, **Créditos** e **Sair**.
- Sistema de **níveis progressivos**, com desbloqueio de conteúdo ao longo do jogo.
- Combate contra diferentes tipos de inimigos, incluindo **Default**, **Speedy**, **Tank**, **Sniper** e um **boss final**.
- Mecanismo de **exploração e resolução de puzzles**, com foco na recolha de chaves para avançar.
- Cena final de **créditos**, encerrando a experiência de jogo.

## Estrutura de Ficheiros

- **Robots Carnage.exe**: executável principal do jogo.
- **Robots Carnage_Data/**: ficheiros de dados e recursos utilizados pelo jogo Unity.
- **MonoBleedingEdge/**: runtime necessário para a execução do projeto.
- **Relatório da PAP Francisco Rodrigues 3ºPI Nº8868.docx**: relatório completo com a descrição do projeto, desenvolvimento e análise funcional.

## Como Executar

1. Acede à pasta **Robots Carnage**.
2. Executa o ficheiro **Robots Carnage.exe**.
3. Se necessário, assegura que o ambiente de execução do Windows suporta a aplicação Unity.
